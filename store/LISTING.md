# Chrome Web Store listing

**Name:** Codex Usage in Sidebar

**Summary:** See remaining Codex usage and reset countdowns beside your ChatGPT profile.

## Description

See your remaining 5-hour and weekly Codex limits in ChatGPT's sidebar. Hover for reset dates or click to open usage settings. Usage refreshes every minute while the tab is visible.

After installing, reload ChatGPT and expand the sidebar. You'll need a signed-in account with Codex usage limits. A dash means the data is unavailable.

Uses your ChatGPT session to fetch usage from ChatGPT. No analytics, ads, or data sent to the developer. Does not read your conversations.

Independent extension, not affiliated with OpenAI. Changes to ChatGPT may temporarily break the display.

## Privacy fields

- **Single purpose:** Show remaining Codex usage and reset countdowns in ChatGPT's sidebar.
- **Site access:** `https://chatgpt.com/*` is needed to find the profile row and fetch session and usage data.
- **Remote code:** None. All code is bundled.
- **Data handled:** Authentication information (session token), website content (usage limits), and account details included in the session response. Only the token and usage values are used, in memory. Requests go only to ChatGPT.
- **Data use:** No selling, unrelated use, or use for credit or lending decisions.
- **Privacy URL:** https://github.com/zizhengwu/codex-limits-in-sidebar/blob/main/PRIVACY.md

Publish the privacy file before submitting. Match the dashboard disclosures to this data handling, including data processed only in memory.
