# Simple ChatGPT Limits

See your remaining ChatGPT limits at a glance in the bottom-left sidebar, with no floating panel or setup needed.

![ChatGPT limits and reset countdowns in the ChatGPT sidebar](store/screenshot-1280x800.png)

## Chrome extension

[Install Simple ChatGPT Limits from the Chrome Web Store](https://chromewebstore.google.com/detail/chatgpt-limits-in-sidebar/embgehonmfhhdcdjdmajjdcipnklpjcg). Then reload ChatGPT and expand the sidebar.

### Install locally

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this folder.
3. Reload ChatGPT and expand the sidebar.

## Userscript

With Tampermonkey or Violentmonkey installed, [install the script](https://raw.githubusercontent.com/zizhengwu/simple-chatgpt-limits/main/chatgpt-limits.user.js) and reload ChatGPT.
