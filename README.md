# Simple ChatGPT Limits

See your remaining ChatGPT limits at a glance, with no floating panel or setup needed.

![Simple ChatGPT Limits showing remaining limits and reset countdowns](store/screenshot-1280x800.png)

## Chrome extension

[Install](https://chromewebstore.google.com/detail/chatgpt-limits-in-sidebar/embgehonmfhhdcdjdmajjdcipnklpjcg) from the Chrome Web Store.

## Userscript

With Tampermonkey or Violentmonkey installed, [install the script](https://raw.githubusercontent.com/zizhengwu/simple-chatgpt-limits/main/chatgpt-limits.user.js) and reload ChatGPT.
